完善标准化文档模板：提升细节完整度和可执行性

主要变更：

**1. proposal.md 模板增强**
- 添加问题陈述、目标、成功标准、利益相关者、时间线和风险缓解等章节
- 添加审批流程，明确技术负责人和产品负责人
- 添加备选方案对比表，帮助决策
- 添加开放问题章节，便于追踪未决事项

**2. spec.md 模板增强**
- 添加需求ID、优先级（Gherkin格式的测试场景、验收标准、依赖关系
- 添加 MODIFIED 需求的变更原因和影响分析
- 添加 REMOVED 需求的迁移计划和移除前检查清单
- 添加需求交叉引用表和 Schema 验证

**3. design.md 模板增强**
- 添加技术选型表（框架、数据库、缓存、消息队列）
- 添加架构决策记录（ADR）模板
- 添加组件图、实体关系图、数据流图
- 添加 API 设计（REST 端点表、请求/响应示例、错误处理）
- 添加安全设计（认证授权、数据保护）
- 添加文件变更清单（新文件、修改文件、删除文件）
- 添加风险评估、NFR、测试策略、部署策略

**4. tasks.md 模板增强**
- 添加需求关联、NFR 验证映射
- 添加标准文件结构目录
- 添加任务模板（类型、预估时间、文件变更、接口定义、验证清单）
- 添加完整 TDD 步骤（RED-GREEN-REFACTOR 循环）
- 添加集成测试任务和最终验证清单
- 添加进度台账和问题追踪

这些模板为 AI 代理提供了更加结构化、细节化的指导，确保执行时能够遵循统一的规范和质量标准。
