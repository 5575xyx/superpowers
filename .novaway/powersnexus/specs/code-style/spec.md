## 1. 模块概述

### 1.1 功能描述

代码风格检查工具（Code Style Checker）是一个跨语言的代码规范检查工具，能够自动扫描项目中的代码文件，检测不符合编码规范的问题，并生成结构化的检查报告。

### 1.2 设计目标

1. **统一性** — 提供统一的检查接口，支持多语言
2. **可扩展性** — 通过规则引擎支持自定义规则
3. **高性能** — 在合理时间内完成大项目扫描
4. **易用性** — 提供清晰的报告和简单的 CLI 接口

### 1.3 适用范围

适用于需要在开发过程中保持代码风格一致性的中大型项目，特别是：
- 多语言混合项目
- 团队协作项目
- 开源项目
- 持续集成环境

## 5. 数据模型

### 5.1 Issue

```typescript
interface Issue {
  file: string;        // 文件路径
  line: number;        // 行号
  column: number;      // 列号
  rule: string;        // 规则名称
  severity: 'error' | 'warning' | 'info';
  message: string;     // 问题描述
  suggestion?: string; // 修复建议
}
```

### 5.2 ScanResult

```typescript
interface ScanResult {
  files: number;       // 扫描文件数
  issues: Issue[];     // 问题列表
  summary: {
    error: number;     // 错误数
    warning: number;   // 警告数
    info: number;      // 提示数
  };
  time: number;        // 扫描耗时（ms）
}
```
