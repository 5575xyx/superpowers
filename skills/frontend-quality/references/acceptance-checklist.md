# 前端视觉验收清单

完成界面实现后逐项检查，并只记录与当前界面相关的项目。

## 视觉与层级

- [ ] 页面只有一个视觉上明确的主操作。
- [ ] 标题、正文、辅助信息和危险操作的层级可通过留白、字号、字重和对比度辨识。
- [ ] 颜色、圆角、阴影、图标和间距使用现有系统或本次定义的令牌。
- [ ] 文案、数据长度和图片比例接近真实场景；空状态不使用无意义占位内容。

## 响应式与状态

- [ ] 在桌面与移动端宽度均检查过，无横向滚动、裁切或重叠。
- [ ] 窄屏优先展示核心内容，次要内容以合理方式折叠或重排。
- [ ] 交互组件具备默认、焦点、禁用及适用的悬停/按下状态。
- [ ] 异步区域具备适用的加载、空、错误和成功反馈。

## 可访问性与性能

- [ ] 键盘可抵达全部交互元素，焦点状态清晰，弹层有退出路径。
- [ ] 图标按钮、图片、表单和标题层级具有语义或替代文本。
- [ ] 文字与背景对比度足够，状态不只依赖颜色表达。
- [ ] 图片预留尺寸；非首屏资源不阻塞主要内容；动效尊重减少动态效果偏好。

## 证据

- [ ] 已记录桌面预览或截图。
- [ ] 已记录移动端预览或截图。
- [ ] 已记录发现的问题及修复结果。
